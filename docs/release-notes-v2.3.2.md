# HScreenFilter v2.3.2

> Windows 屏幕滤镜 · 实时 3D LUT 调色覆盖层

## 新增：按键兼容模式

设置页 →「全局快捷键」新增 **按键兼容模式（不独占游戏按键）**：

- 开启后不再调用 `RegisterHotKey`，所有全局/配置热键改用**被动低级键盘钩子**；
  钩子只观察、不消费按键，游戏和其它程序仍能收到同一按键，也能正常进入按键绑定界面。
- 关闭后恢复 `RegisterHotKey` 独占注册（默认行为）。
- 偏好写入 `profiles.json` 顶层 `HotkeyCompat`（默认 false），切换时自动注销并重新注册全部热键。
- 设置页已说明代价：如果游戏自己的键盘钩子优先消费了该键，本程序的热键可能不响应。

## 修复：快捷键与游戏冲突

- **不再无条件安装全局键盘钩子**：只有 `RegisterHotKey` 失败的组合才按需装钩子，最后一条兜底组合注销后立即卸载。
- 兜底钩子只观察、不消费按键；按住热键按 keyDown 状态去重，不再反复触发。
- 钩子改到 `MessageWindow` 高优先级消息线程，不占用 UI/WebView2 线程。
- **捕获钩子不再在回调里做慢操作**：只取 VK/扫描码/修饰键并 `PostMessage`，注册热键和通知页面都回到 UI 线程，避免超过系统钩子超时导致游戏丢键。
- 捕获支持 **Alt 组合**（`WM_SYSKEYDOWN`）、忽略注入键、15 秒无按键自动取消、钩子安装失败给页面明确提示。
- 修饰键状态在钩子回调里采集并随消息传递，避免 `Ctrl+F` 被捕获成 `F`。

## 修复：滤镜强度一会强一会弱

- 根因：暗场景优化的自适应权重每秒按 5 个 16×16 采样块的平均亮度重算；游戏里手电/明暗切换会让权重在 0.5↔1.0 之间反复跳。
- 新增 15s 时间常数平滑 + 每 2.5s 最多 0.04 的变化限速 + 0.02 死区；短促明暗变化不再直接改强度，持续换场景时缓慢过渡。
- `--selftest` 新增回归：交替 0.05/0.34 序列下单次变化 ≤0.04、总变化 ≤0.25。

## 新 UI

- `webui2/` 替换为新的 Apple 风格界面：配置下拉、设置页、快捷键分组、预设侧栏、HSL 调色盘。
- 窗口默认内容区 **650×678 DIP**（按系统 DPI 换算物理像素；外层另含系统标题栏/边框）。
- 650 宽下自动隐藏「DXGI 桌面复制 · SDR」说明，保留完整的引擎状态。

## 安装

1. 下载 `HScreenFilter-v2.3.2.zip` 并解压；
2. 确认 `HScreenFilter.exe`、`WebView2Loader.dll`、`webui2\` 在同一目录；
3. 运行 `HScreenFilter.exe`；首次使用需要 Microsoft Edge WebView2 Runtime。

从 v2.3.1 升级不需要迁移配置：`profiles.json` 保持兼容，新增字段 `HotkeyCompat` 默认关闭。

完整变更见仓库根目录 `CHANGELOG.md`。
