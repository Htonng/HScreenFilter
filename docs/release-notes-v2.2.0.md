# HScreenFilter v2.2.0

C++17 滤镜引擎 + Edge WebView2 Flat Design UI。本版在 v2.1.1 的基础上完成单遍渲染、帧节拍稳定、启动路径重构、控件持久化与自启白屏修复。

## 本次重点（2026-10-24）

### 修复开机自启后 WebView2 白屏

- 根因：`--autostart` +“自启后自动进入托盘”时主窗口从未显示过，`CreateCoreWebView2Controller` 却在隐藏窗口上创建。导航与 JS 均正常，但没有可见合成表面，从托盘恢复只剩白底。
- 修复：自启时先把窗口用 `SW_SHOWNOACTIVATE` 显示在屏幕外，页面 `ready` 后再隐藏并归位；恢复窗口时显式 `put_IsVisible(TRUE)` + 重新 `put_Bounds`。
- 加固：设置加载期背景色；WebView2 环境/控制器失败、12/24 秒未就绪时把窗口移回屏幕内并给出明确错误框；导航失败自动重载一次；第二个实例唤起已有实例时走完整恢复路径。

### 降低 LUT 首次启动卡顿

- 滤镜启动改为页面 `ready` 后错峰执行，不再与 WebView2 冷启动同时抢 GPU/CPU。
- 着色器增加进程级缓存，发布版后台预热；本机实测着色器管线 `125ms → 0ms`，`LutEngine::Start` 总耗时 `312ms → 188ms`。
- 启动自检从第 90 帧推迟到 5 秒后且只做一次；发布版移除整张 64³ LUT 的 GPU 回读。
- 参数未变化不再标脏重建；场景自适应权重在启动前 2.5 秒不触发重建。
- 新增启动阶段、首帧捕获/呈现、`Start` 总耗时日志，便于定位环境相关卡顿。

### 控件功能核查与持久化

- 滤镜总开关、显示器启用、按应用切换、开机自启、自启进托盘、界面主题立即写入 `profiles.json`。
- 开机自启以注册表实际状态为准，失败时回滚并提示。
- HSL 以宿主下发的 `lutActive` 为准；LUT 引擎回退到放大镜/伽马时明确提示。
- 修复切屏快照错位、色系 chip 聚焦丢失、配置上移/下移无提示等问题。
- 完整核查表见仓库 `docs/控件功能核查.md`。

### LUT 性能损耗确认

手动启用 LUT、启用 LUT 配置、点击 LUT 组预设时，先弹出性能损耗确认，说明 DXGI 全屏捕获、64³ LUT 逐像素采样与 8 次邻域后处理的影响；提供“仍然启用 / 保持关闭”和“本次运行不再提示”。

## v2.2.0 其他内容

- **单遍渲染合并**：移除 `R16G16B16A16_FLOAT` 中间纹理与两次全屏清屏；后处理内联进单遍像素着色器，五项后处理全为 0 时走 `PostActive` 快路径。
- **帧节拍稳定**：窗口模式固定 `Present(1)` 由 DWM 对齐 vblank，`SetMaximumFrameLatency(1)`；启动保护期 1.5 秒、统计预热 1 秒；桌面位图未变的重复帧不再重绘；隐藏覆盖层期间不拷贝整屏纹理、不呈现。
- **捕获与探测**：DXGI 桌面复制固定 `B8G8R8A8_UNORM` / SDR 管道；场景探测延迟一帧、`D3D11_MAP_FLAG_DO_NOT_WAIT` 非阻塞回读；捕获失效带退避重试并自动隐藏/恢复覆盖层。
- **性能与诊断**：异步日志（渲染线程不碰磁盘）；LUT 重建限速 30ms；实时帧率 OSD 与每秒帧率明细；启动阶段与首帧日志。
- **引擎自愈**：5 秒看门狗重建停止的 LUT 引擎，重设被驱动重置的伽马曲线。
- **UI**：高级调整（锐化/降噪/边缘增强/清晰度/画质增强）、HSL 9 通道、LUT 组预设、按应用切换、配置/热键/导入导出、托盘、主题等。

## 安装

1. 解压 zip。
2. 运行 `HScreenFilter.exe`。
3. 系统需安装 **Microsoft Edge WebView2 Runtime**（Windows 11 通常自带；[下载](https://developer.microsoft.com/microsoft-edge/webview2/)）。
4. 配置沿用 `%LocalAppData%\HScreenFilter\profiles.json`，字段与旧版兼容。

## 验证

- `--selftest` 退出码 0（JSON 往返、着色器编译、D3D11 设备、显示器枚举、颜色矩阵）。
- `--enginetest-cycle` 退出码 0（覆盖层隐藏/恢复未阻塞 Present）。
- 自启白屏回归：`MinimizeToTray=true` + `--autostart` 启动后窗口隐藏，从托盘/第二实例恢复后 WebView2 UI 正常显示。
- 启动回归（LUT 已启用）：着色器预热约 140ms、首帧/首帧呈现 0ms、1 秒窗口 180fps、自检 5 秒后执行。

## 已知限制

- “垂直同步”固定开启且锁定：窗口模式 `Present(1)` 由 DWM 对齐 vblank。
- 非 LUT 引擎下 HSL/高级调整禁用；参数仍会保存。
- HDR 显示器上 LUT 强制开启、不可关闭（放大镜/伽马对 HDR 内容无效）。
- “LUT 性能确认”的“本次运行不再提示”只作用于当前进程。
