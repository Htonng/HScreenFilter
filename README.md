# HScreenFilter 屏幕滤镜

<p align="center">
  <img src="HScreenFilter/assets/Full-logo.PNG" alt="HScreenFilter Logo" width="320"/>
</p>

一个基于 **WinUI 3** 的 Windows 屏幕滤镜工具，通过滑块实时调节屏幕的**亮度、对比度、鲜艳度、亮部、暗部**，并内置**真·逐像素 HSL 调色盘**（8 色系分色系），支持**全局快捷键一键切换配置文件**。底层采用 **DXGI 逐像素着色器引擎**，不触发屏幕捕获隐私边框。关闭窗口后驻留系统托盘，滤镜持续生效。

## 🚀 按应用切换滤镜

想让滤镜**只作用于某些应用**（例如只在浏览器或某个游戏里生效）时，可开启“启用按应用切换”并维护一个**检测列表**：

1. 点击 **“添加应用…”**，输入目标应用的进程名（不带 `.exe`，例如 `chrome` 或 `notepad`），可选填窗口标题（按子串匹配），并选择一个**绑定配置**（“不切换配置”或某套已保存的配置）。
2. 也可以点击 **“用当前前台应用添加”**，自动抓取当前前台应用并填入。
3. 列表可随时 **编辑 / 删除**。

开启后：
- **某绑定进程在前台** → 自动应用其绑定的配置（未绑定配置则按当前设置应用），滤镜启用。
- **列表内有进程但都不在前台** → 滤镜自动关闭。
- **列表为空** → 不限制，按手动开关。

> 使用技巧：可以把“按应用切换”和“配置文件”“全局快捷键”结合使用——某进程在前台时自动套用对应配置，切走后自动关闭。

## 🎨 可被 OBS / 录屏捕获

在“配置与快捷键”卡片底部开启 **“UI 与滤镜层可被 OBS 捕获”** 后，滤镜覆盖层与 UI 即可被 OBS 等屏幕录制软件捕获（覆盖层自动从自身捕获排除，防止自反馈）。

> OBS 请使用 **「显示器捕获」（WGC 模式）** 即可同时录到滤镜效果与 UI；不要用「窗口捕获」（WinUI 窗口 / 覆盖层用窗口捕获会黑屏或选不到）。若使用旧版 OBS（DXGI 显示器捕获）可能看不到，请升级到新版（WGC 默认）。

## 🛠️ 技术原理

**默认（DXGI 引擎）**：基于 **Vortice.Direct3D11** 的全 GPU 渲染管线——创建一个置顶的原始 Win32 覆盖层窗口，通过 DXGI Desktop Duplication 捕获桌面，在 GPU 内复制到渲染纹理，用**逐像素 HSL 着色器**处理并呈现。全程 GPU、无 CPU 往返，支持**真正的逐色系选择性调整**，且不触发 Windows 11 屏幕捕获隐私边框。

- **HSL 调色**：每像素转 HSL → 按色系掩码（红/橙/黄/绿/青/蓝/紫/品红）加权叠加色相旋转、饱和度缩放、明度偏移 → 转回 RGB。
- **五个核心调节**（亮度/对比度/鲜艳度/亮部/暗部）与色温在像素着色器中一并处理。
- **引擎切换**：开启 DXGI 引擎 = HSL 可用；关闭则回退到**放大镜 API**（MagSetFullscreenColorEffect，5×5 颜色矩阵，仅支持整屏线性调整，不支持分色系 HSL）。

> **引擎回退链**：DXGI 逐像素着色器 → 放大镜颜色矩阵（Windows 10 1903+）→ 显卡伽马曲线（SetDeviceGammaRamp，鲜艳度与 HSL 不可用）。应用会自动探测并按顺序回退。
